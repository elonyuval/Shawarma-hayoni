# שווארמה עיוני — אתר

אתר סטטי, RTL, Mobile First. בלי build, בלי dependencies, בלי framework —
HTML + CSS + JavaScript רגיל. פותחים קובץ ועורכים.

```
index.html            — כל המבנה של הדף
assets/css/style.css  — כל העיצוב (מחולק לסקשנים ממוספרים)
assets/js/data.js     — ⬅ כל המידע העסקי. זה הקובץ שאתה עורך.
assets/js/main.js     — לוגיקה: אנימציות, תפריט, אינטראקציות
images/               — כל התמונות (ראה images/README.md)
images/logo*.png      — הלוגו, חולץ ונוקה מצילום המסך
```

## הרצה מקומית

```bash
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

(צריך שרת ולא פתיחה ישירה של הקובץ, כי הנתיבים באתר מוחלטים — `/assets/...`)

## מצב הנתונים

הפרטים באתר נאספו ממקורות פומביים (דפי זהב, ZAP Rest, אינסטגרם, פייסבוק, מוביט).
ב־`data.js` כל שדה מסומן:

| סימון | פירוש |
|---|---|
| ✅ VERIFIED | נמצא במקור פומבי |
| ⚠️ VERIFY | נמצא במקור פומבי אבל **צריך אישור שלך** |
| ⛔ PLACEHOLDER | אין מידע — צריך למלא |

### מה שדורש אישור שלך (⚠️)

- [ ] **הכתובת** — דפי זהב רשמו *גיבורי ישראל 14*, איזי רשמו *שדרות גיבורי ישראל 10*.
      לבחור נכון ולעדכן גם את `mapEmbedSrc` ואת `links.googleMaps`.
- [ ] **שעות פעילות** — א׳–ה׳ 07:30–19:30, ו׳ 09:00–13:00.
- [ ] **טלפון** — 09-885-8804.
- [ ] **קישור ההזמנות ב־10bis** — לוודא שהעמוד פעיל. אם אין הזמנות אונליין, לרוקן את `links.order`.
- [ ] **גוף הכשרות** — לרשום מה שכתוב על התעודה בקיר.
- [ ] **רשימת התוספות** — להתאים למה שבאמת יש.

### מה שחסר לגמרי (⛔)

- [ ] **דירוג גוגל** (`rating.score` + `rating.count`) — עד שממלאים, הבלוק לא מוצג בכלל.
- [ ] **קישור לעמוד הביקורות בגוגל** (`links.googleReviews`).
- [ ] **קואורדינטות** (`geo`) — ל־structured data.
- [ ] **ציטוטי ביקורות אמיתיים** — ראה למטה.
- [x] **תמונות** — צילומים אמיתיים של העסק נכנסו לכל המקומות ✅
- [ ] **צילום שניצל** — חסר. כרטיס השניצל הוסר זמנית מסקשן האוכל.
- [ ] **צילום נפרד לפרגית ולחזה עוף** — שניהם כרגע קרופים של אותה צלחת.
- [ ] **דומיין** — להחליף `https://example.com/` ב־`index.html`, `robots.txt` ו־`sitemap.xml`.

### לגבי הביקורות — חשוב

שלושת המשפטים בסקשן הביקורות **אינם ציטוטים**. הם ניסוח שלנו שמסכם את מה
שמופיע בביקורות הפומביות, ומוצגים בלי מרכאות עם הערה שאומרת את זה.
כשיהיו ציטוטים מדויקים: להעתיק אותם ל־`reviews` ולסמן `verbatim: true` —
אז הם יוצגו במרכאות עם שם הכותב.

## נגישות

- עובר `axe-core` בתקן WCAG 2.1/2.2 AA — 0 חריגות (דסקטופ ומובייל).
- ניגודיות: טקסט משני הועלה ל־62% אטימות, טקסט על כפתור כתום הוא כהה (6.2:1).
- ניווט מקלדת מלא + `:focus-visible` גלוי, `aria-current` על הסקשן הפעיל.
- ה־marquee נעצר במעבר עכבר, וכבוי לגמרי ב־`prefers-reduced-motion`.
- טווחי שעות ומספרי טלפון מבודדים ל־LTR כדי שלא יתהפכו בתוך RTL.
- אזורי מגע במובייל ≥ 44px.

## דברים שכדאי לדעת

- **תמונות:** כל תמונה חסרה מוצגת כ־placeholder מעוצב עם שם הקובץ. ברגע שהקובץ קיים
  הוא נטען ומחליף את ה־placeholder. אין צורך לשנות קוד.
- **קישור ריק** ב־`links` פשוט לא יוצג (רשתות חברתיות, ביקורות, הזמנות).
- **structured data** (Restaurant) נבנה אוטומטית מתוך `data.js` — אין כפילות מידע.
