# תמונות

## ⚠️ מה שנמצא כאן עכשיו הן תמונות דוגמה

`hero.jpg`, `shawarma.jpg`, `pargit.jpg`, `schnitzel.jpg`, `chicken.jpg`,
`about.jpg`, `gallery-1..4.jpg` — **אלה לא צילומים של העסק**. אלה לוחות
מעוצבים בגוונים חמים עם שם המנה, שנועדו רק כדי שהפריסה תיראה מלאה.

**חובה להחליף אותם בצילומים אמיתיים לפני עלייה לאוויר.** להעלות קובץ
באותו שם — והוא מתחלף לבד, בלי לגעת בקוד.

---

## מה צריך להעלות לכאן

כל התמונות באתר הן כרגע **placeholders מעוצבים**.
ברגע שמעלים לתיקייה הזאת קובץ בשם הנכון — הוא מחליף את ה־placeholder אוטומטית.
אין צורך לגעת בקוד.

| קובץ | איפה מופיע | יחס מומלץ | גודל מומלץ |
|---|---|---|---|
| `hero.jpg` | תמונת הפתיחה הגדולה | 16:9 / לרוחב | 2400×1400, עד ~400KB |
| `shawarma.jpg` | כרטיס שווארמה (הגדול) | 4:5 / מרובע | 1600×1600 |
| `pargit.jpg` | כרטיס פרגית | 16:10 | 1600×1000 |
| `schnitzel.jpg` | כרטיס שניצל | 4:5 | 1200×1500 |
| `chicken.jpg` | כרטיס חזה עוף | 4:5 | 1200×1500 |
| `about.jpg` | סקשן "על עיוני" | 4:5 לאורך | 1400×1750 |
| `gallery-1.jpg` … `gallery-6.jpg` | גלריה | מעורב | 1400px רוחב מינימום |

## כבר קיים ✅

הלוגו חולץ מצילום המסך ששלחת — הרקע החום הוסר, וכפתור ה־Google Lens נוקה:

| קובץ | מה זה | איפה |
|---|---|---|
| `logo.png` | הלוקאפ המלא, רקע שקוף | Footer, תמונת שיתוף |
| `logo-mark.png` | הסמל בלבד, חתוך לעיגול | Header |
| `favicon.png` | אייקון לשונית | הדפדפן |
| `apple-touch-icon.png` | אייקון למסך הבית | נייד |
| `og.jpg` | תמונת שיתוף 1200×630 | וואטסאפ, פייסבוק |

אם יש לך את הלוגו כקובץ מקורי (וקטור/PNG באיכות גבוהה) — פשוט דרוס את
`logo.png` ו־`logo-mark.png` באותם שמות והאתר יתעדכן. המקור הנוכחי הוא
צילום מסך ב־1179px, מספיק לגדלים שבהם הוא מוצג אבל לא לדפוס.

## טיפים
- **פורמט:** עדיף `.webp` על `.jpg` (קטן ב־30–50%). אם עוברים ל־webp, לעדכן את שמות הקבצים ב־`assets/js/data.js`.
- **משקל:** לשאוף לפחות מ־300KB לתמונה. תמונות ענקיות מאטות את האתר.
- **קומפוזיציה:** התמונות נחתכות ב־`object-fit: cover` — להשאיר "אוויר" בשוליים כדי שכלום חשוב לא ייחתך.
- **חושך:** על התמונות יש שכבת gradient כהה כדי שהטקסט יישאר קריא. תמונות בהירות מדי בתחתית עלולות להקשות על הקריאה.
